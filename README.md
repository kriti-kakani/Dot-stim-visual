# Dot-stim-visual
This is a dot stim experiment where participants need to identify the predominant direction of movement for certain moving dots. Certain visualizations like scatter plots and bar chart at the end.

Participants must decide whether the dots are moving towards the left or right and respond using the 'left' and 'right' keyboard arrow key. The experiment also measures response accuracy and reaction time and shows the same through bar charts and scatter plots at the end.
